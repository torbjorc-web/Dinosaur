# Dinoatlas

Dinoatlas er et lite oppslagsverk og en quiz om dinosaurer.

## Kom i gang

Krever Python 3. Installer avhengighetene og start Flask-appen:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Åpne deretter adressen som vises i terminalen (vanligvis http://127.0.0.1:5000).

## Innhold

- `app.py` – Flask-applikasjonen og sidene
- `catalog.py` – dinosaurdata
- `templates/` – HTML-maler
- `static/` – CSS, bilder og andre statiske filer
